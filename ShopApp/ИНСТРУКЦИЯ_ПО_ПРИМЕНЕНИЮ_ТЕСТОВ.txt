1. ОБЗОР
═══════════════════════════════════════════════════════════════════════════════

Проект ShopApp.Tests содержит полный набор unit-тестов для проверки
функциональности приложения ShopApp - системы управления онлайн-магазином.

СОЗДАННЫЕ ТЕСТЫ:
• LoginFormTests.cs      - Тесты аутентификации (4 теста)
• RegisterFormTests.cs   - Тесты регистрации (3 теста)
• ProductFormTests.cs    - Тесты фильтрации товаров (6 тестов)
• BasketFormTests.cs     - Тесты корзины (6 тестов)
• SearchFilterTests.cs   - Тесты поиска (6 тестов)
• GlobalsTests.cs       - Тесты глобальных переменных (10 тестов)
• TestScenarios.cs       - Документация сценариев

ВСЕГО: 40+ unit-тестов

ШАГ 2: Открытие решения
────────────────────────

2. File → Open → Project/Solution
3. Выберите файл ShopApp.sln
4. Дождитесь загрузки проекта

ШАГ 3: Восстановление NuGet пакетов (если необходимо)
────────────────────────────────────────────────────
1. Правой кнопкой на solution
2. Restore NuGet Packages
3. Дождитесь восстановления

ШАГ 4: Проверка подключения к базе данных
──────────────────────────────────────────

Если база данных недоступна, некоторые тесты будут помечены как [Ignore]

4. ЗАПУСК ТЕСТОВ
═══════════════════════════════════════════════════════════════════════════════

СПОСОБ 1: Через Test Explorer (РЕКОМЕНДУЕТСЯ)
─────────────────────────────────────────────

1. Build → Build Solution (или Ctrl+Shift+B)

2. Откройте Test Explorer:
   • Test → Windows → Test Explorer
   • Или: Ctrl+E, T

3. В Test Explorer вы увидите список всех тестов

4. Запустите тесты:
   • "Run All" - запустить все тесты
   • "Run Failed Tests" - запустить только упавшие
   • Правой кнопкой на группе - запустить тесты из группы
   • Двойной клик - запустить конкретный тест

5. Результаты появятся в Test Explorer:
   ✅ Зеленый кружок = тест пройден
   ❌ Красный крест = тест упал
   ⚠️ Желтый треугольник = тест пропущен

СПОСОБ 2: Через командную строку
─────────────────────────────────

1. Откройте Developer Command Prompt for VS

2. Перейдите в директорию проекта:
   cd D:\GitHub\ShopApp

3. Запустите тесты:
   dotnet test
   или
   msbuild ShopApp.sln /t:Test

СПОСОБ 3: Измененный запуск
────────────────────────────

Если нужно запустить только определенные тесты:

1. В Test Explorer:
   • Filter by name: введите название теста
   • Run All

2. Через код:
   Добавьте [Ignore] к тестам, которые не хотите запускать:
   
   [TestMethod]
   [Ignore]
   public void MyTest() { ... }

ЗАПУСК ПО КАТЕГОРИЯМ:
─────────────────────
Все тесты помечены категориями [TestCategory]:
• Critical - критичные тесты
• High - важные тесты
• Medium - средние тесты

Запуск только Critical тестов:
Test Explorer → Filter → "Critical" → Run All

6. ОТЛАДКА ТЕСТОВ
═══════════════════════════════════════════════════════════════════════════════

ОТЛАДКА ОДНОГО ТЕСТА:
─────────────────────

1. Установите breakpoint в тесте:
   • Откройте файл с тестом
   • Кликните слева от номера строки
   • Появится красная точка

2. Запустите тест в режиме отладки:
   • Правой кнопкой на тесте
   • Debug Selected Tests
   • Или F5

3. Используйте инструменты отладки:
   • F10 - шаг с обходом (Step Over)
   • F11 - шаг с заходом (Step Into)
   • F5 - продолжить выполнение
   • Shift+F5 - остановить отладку

4. Просмотр переменных:
   • Наведите курсор на переменную
   • Смотрите в Debug → Watch
   • Смотрите в Debug → Locals

ПРИМЕР ОТЛАДКИ:
───────────────
public void CalculateTotal_Test()
{
    var items = new List<BasketItem>();
    // ← Breakpoint здесь
    
    items.Add(new BasketItem { Price = 100, Quantity = 2 });
    
    decimal total = items.Sum(i => i.Price * i.Quantity);
    // ← Проверьте значение total
    
    Assert.AreEqual(200, total);
}

ИСПОЛЬЗОВАНИЕ ASSERT:
─────────────────────
Assert.AreEqual(expected, actual);      // Проверка равенства
Assert.IsTrue(condition);                // Проверка истинности
Assert.IsFalse(condition);               // Проверка ложности
Assert.IsNull(object);                   // Проверка null
Assert.IsNotNull(object);                // Проверка not null
Assert.ThrowsException<Exception>(() => action()); // Проверка исключения

═══════════════════════════════════════════════════════════════════════════════

ШАБЛОН НОВОГО ТЕСТА:
────────────────────

[TestMethod]
[TestCategory("High")]
public void MyNewTest_Name_ShouldDoSomething()
{
    // Arrange - подготовка данных
    var input = "test data";
    var expected = "expected result";
    
    // Act - выполнение действия
    var result = ProcessData(input);
    
    // Assert - проверка результата
    Assert.AreEqual(expected, result);
    Assert.IsNotNull(result);
}

СТРУКТУРА ТЕСТА (AAA Pattern):
───────────────────────────────
Arrange (Подготовка):
• Создание тестовых данных
• Настройка объектов
• Инициализация переменных

Act (Действие):
• Вызов тестируемого метода
• Выполнение операции

Assert (Проверка):
• Сравнение результата с ожиданием
• Проверка исключений
• Валидация состояний

ПРИМЕР СОЗДАНИЯ ТЕСТА:
──────────────────────
[TestMethod]
[TestCategory("Medium")]
public void ProductForm_AddToBasket_NewProduct_ShouldAdd()
{
    // Arrange
    int productId = 1;
    int basketId = 10;
    int expectedCount = 1;
    
    // Act
    var result = AddProductToBasket(productId, basketId);
    
    // Assert
    Assert.AreEqual(expectedCount, result.Count);
}

8. РЕШЕНИЕ ПРОБЛЕМ
═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 1: "Cannot find test methods"
──────────────────────────────────────────
РЕШЕНИЕ:
• Build → Rebuild Solution
• Test Explorer → Refresh
• Убедитесь, что есть [TestMethod] атрибут
• Проверьте что файл .csproj содержит файл

ПРОБЛЕМА 2: "Database connection error"
──────────────────────────────────────────
РЕШЕНИЕ:
• Проверьте SQL Server службу: Services → SQL Server
• Проверьте connection string в Globals.cs
• Используйте [Ignore] для тестов требующих БД
• Или создайте mock базу данных

ПРОБЛЕМА 3: "Test failed - Assert failed"
─────────────────────────────────────────
РЕШЕНИЕ:
• Откройте Test Explorer → Failed Tests
• Прочитайте сообщение об ошибке
• Установите breakpoint
• Запустите отладку
• Проверьте значения переменных

ПРОБЛЕМА 4: "Cannot see Test Explorer"
───────────────────────────────────────
РЕШЕНИЕ:
• Test → Windows → Test Explorer
• View → Other Windows → Test Explorer
• Или: Ctrl+E, T

ПРОБЛЕМА 5: "Tests run infinitely"
────────────────────────────────────
РЕШЕНИЕ:
• Проверьте тесты на бесконечные циклы
• Установите timeout для теста:
  [TestMethod]
  [Timeout(5000)] // 5 seconds
  public void MyTest() { ... }

ПРОБЛЕМА 6: "Missing references"
────────────────────────────────
РЕШЕНИЕ:
• Правой кнопкой на проект → Manage NuGet Packages
• Установите Microsoft.VisualStudio.QualityTools.UnitTestFramework
• Rebuild Solution
