# Unit Tests для ShopApp

## Обзор

Этот проект содержит unit-тесты для приложения ShopApp - системы управления онлайн-магазином одежды.

## Структура проекта

```
ShopApp.Tests/
├── Properties/
│   └── AssemblyInfo.cs
├── LoginFormTests.cs           - Тесты аутентификации
├── RegisterFormTests.cs        - Тесты регистрации
├── ProductFormTests.cs         - Тесты фильтрации товаров
├── BasketFormTests.cs          - Тесты корзины
├── SearchFilterTests.cs        - Тесты поиска и фильтрации
├── GlobalsTests.cs            - Тесты глобальных переменных
├── TestScenarios.cs           - Документация сценариев
├── ShopApp.Tests.csproj       - Файл проекта
├── App.config                 - Конфигурация
└── README.md                  - Этот файл
```

## Настройка тестовой среды

### Требования

- .NET Framework 4.8
- Microsoft Visual Studio Test Framework
- SQL Server или Mock база данных для тестов

### Установка зависимостей

```bash
# Откройте solution в Visual Studio
# Щелкните правой кнопкой на ShopApp.Tests -> Manage NuGet Packages
# Установите необходимые пакеты
```

## Запуск тестов

### Через Visual Studio
1. Откройте Test Explorer (Test -> Windows -> Test Explorer)
2. Выберите "Run All" или запустите отдельные тесты

### Через командную строку
```bash
# Запустить все тесты
mstest /testcontainer:ShopApp.Tests\bin\Debug\ShopApp.Tests.dll

# Запустить конкретный тест
mstest /testcontainer:ShopApp.Tests\bin\Debug\ShopApp.Tests.dll /test:LoginFormTests
```

## Известные ограничения

1. **База данных**: Некоторые тесты требуют реального подключения к SQL Server
2. **UI тесты**: Тесты Windows Forms требуют mock объектов
3. **Изоляция**: Некоторые тесты могут влиять на глобальные переменные
