# Анализ программы ShopApp и сценарии тестирования

## Обзор приложения

**ShopApp** - это Windows Forms приложение для управления онлайн-магазином одежды, написанное на C# с использованием .NET Framework 4.8.

### Основные компоненты:
1. **Аутентификация**: LoginForm, RegisterForm
2. **Товары**: ProductForm (для пользователей), ProductsForm (для администраторов)
3. **Корзина**: BasketForm
4. **Заказы**: CreateOrderForm, OrdersForm
5. **Администрирование**: AdminForm, UsersForm

---

## 1. КРИТИЧНЫЕ СЦЕНАРИИ ТЕСТИРОВАНИЯ

### 1.1. Аутентификация и безопасность

#### Сценарий TC-001: Успешный вход пользователя (Critical)
**Описание**: Пользователь успешно входит в систему с корректными учетными данными  
**Приоритет**: CRITICAL  
**Шаги**:
1. Ввести валидный email/телефон в поле логина
2. Ввести валидный пароль
3. Нажать кнопку "Войти"
4. Ожидаемый результат: Открытие формы ProductForm (для пользователя) или AdminForm (для администратора)

**Файл теста**: `LoginFormTests.cs -> Authenticate_ValidCredentials_ShouldSucceed()`

#### Сценарий TC-002: Неудачный вход (Critical)
**Описание**: Попытка входа с неверными учетными данными  
**Приоритет**: HIGH  
**Шаги**:
1. Ввести неверный логин
2. Ввести неверный пароль
3. Нажать кнопку "Войти"
4. Ожидаемый результат: Ошибка с красным обрамлением полей

**Файл теста**: `LoginFormTests.cs -> Authenticate_InvalidCredentials_ShouldFail()`

#### Сценарий TC-003: Защита от SQL Injection (Critical)
**Описание**: Проверка защиты от SQL Injection атак  
**Приоритет**: HIGH  
**Тестовые данные**:
- Логин: `admin' OR '1'='1`
- Пароль: `' OR '1'='1`
4. Ожидаемый результат: Отклонение запроса без выполнения SQL-инъекции

**Файл теста**: `LoginFormTests.cs -> Authenticate_SQLInjectionAttempt_ShouldBeRejected()`
